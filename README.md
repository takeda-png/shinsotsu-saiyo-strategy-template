# 新卒採用戦略 設計書テンプレート

中小企業が自社で新卒採用戦略を設計するためのテンプレートです。
「3カ年計画 → 粗利 → 必要人員 → 組織配置 → 採用計画 → 採用戦略」の順で埋めると、採用人数の根拠から年間カレンダー・KPIまでが一本でつながります。

**▶ [設計書テンプレートを開く](採用戦略設計書_テンプレート.md)**

## 構成

| 章 | 内容 |
| --- | --- |
| 0 | 3カ年計画との接続（採用人数を粗利から逆算） |
| 1 | 設計の前提と全体像 |
| 2 | 市場分析（需給・相場・競合・自社の現在地・採用版CEP分析） |
| 3 | 採用ターゲット（2:6:2の質の基準、ペルソナ） |
| 4 | EVP（選ばれる理由） |
| 5 | チャネルと候補者ジャーニー |
| 6 | 選考・内定フォロー設計 |
| 7 | 年間カレンダー |
| 8 | KPIとファネル管理 |
| 9 | 体制・予算・リスク |
| 10 | 社内ワークショップ設計（2時間×2回） |
| 11 | ワークシート7枚 |
| 12 | 展開の型（支援会社向け） |

## 使い方

1. `採用戦略設計書_テンプレート.md` をコピーする
2. 0章から順に埋める。0章が埋まらないうちは採用人数は「仮」のまま扱う
3. 3〜7章は仮説として書き、10章のワーク①②で社内の言葉に上書きして確定する
4. 根拠のない数字は「要確認」のまま残す

## 考え方

- 戦略（誰に・何を）を先に固め、戦術（媒体・イベント）は後から当てる
- 課題が「集客（接点をつくる）」か「グリップ（集めた優秀層を離さない）」かを最初に見極め、工数はそちらに寄せる
- 人数より質。2:6:2の上位2割を本命にし、埋まらなくても基準を下げない
- 新規施策は工数が低く効果が高いものだけ、3つまで
